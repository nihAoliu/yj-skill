# Resolve 课程剪辑与 AI B-roll

按下述已约定流程工作；用户在会话中明确调整的要求优先。不重新逐阶段询问这些默认规则，只在实际内容、画面、费用等约定节点确认具体成果。保留原技能 first-lecture-b-roll，本技能不使用 ChatCut。

## 执行边界

- 接手用户已放入 Resolve 的目标时间线。默认剪辑 **B 模式**：主动压缩重复解释与同质例子；A 模式保留内容、清理表达。默认只制作一个模式版本。
- 原时间线保留作为恢复依据；内容剪辑、包装阶段各保留一个持续更新的工作时间线。首次进入阶段时才建立对应副本，已有工作版本则复用。不自动导出成片，不创建或启动整片渲染任务。
- 日常修改（恢复预告、改字幕、调样式、微调剪辑）直接更新当前工作时间线，不每次新建版本。只有大幅重剪、需要对比两种方案、或测试可能影响工程结构的操作时才新建副本。版本管理见 [resolve-operations.md](references/resolve-operations.md#时间线版本管理)。
- 转写是后台准备：复用 Resolve 转写，缺少则调用原生转写。无需用户手工导出音频/SRT；不自动创建字幕轨。转写不是听觉检查。
- 用户要求中英双语字幕时，使用**同一条字幕轨的两个独立字幕区域（Subtitle Regions）**：R1 中文、R2 英文，默认中文在上、英文在下，各自可编辑文字与样式、时间同步。不得将中英两行合并进同一个字幕条目，也不拆成两条字幕轨。操作与验证见 [resolve-operations.md](references/resolve-operations.md#中英双语字幕区域)。
- B-roll 为 AI 视频，默认 Vox 纸质拼贴。Codex 内置 ImageGen 生成并保存独立首尾帧；外部 API 只用于视频与原生同步音效。不得静默降级成单帧、定格、推拉、循环或其他提供商。
- 同步音效无音乐、歌声、旁白或对白；简单标题为额外可选项，默认无音效。
- 付费前必须提供所选服务商官方详细报价依据并获明确确认。样片通过后全量并发提交剩余任务，遵守公开的服务端限制；不采用默认四路或按完成情况分波次提交。
- 保存每次提交意图及服务任务 ID；未知提交结果不可重发，失败付费任务不得自动重试。
- 包装阶段不 ripple，不改原讲授音量、剪辑、字幕与全片时长；只修改本次拥有且未被用户另行修改的项目。

## 启动与恢复

遵守用户指定的操作通道。用户禁止 computer use/UI 时，只使用 MCP 与脚本；复杂结构无法无损保留时报告具体限制，不调用 UI 绕过。

先发现 davinci_resolve MCP，查询状态及 get_whats_new，按需查询当前脚本接口。不可用时报告缺失，不改用 ChatCut。仅在实际制作需要时启动 Resolve。

在用户工程素材目录下建立独立运行目录；用 `python3 scripts/workflow.py init <run_dir>` 初始化。状态与校验规则见 [state-contract.md](references/state-contract.md)。脚本负责本地几何、报价算术、指纹和任务账本，**不替代人工确认、不调用付费 API、也不控制 Resolve**。提供商适配在选定服务后按实时文档执行。

先回读运行状态、真实工程和时间线，判断当前阶段，不重建已确认副本或重复生成。恢复规则见 [resolve-operations.md](references/resolve-operations.md)。

若当前时间线明显是测试、验证或占位时间线（例如无可听音轨、仅数秒的测试片段、名称含“测试/验证”），不得把它当作目标进行复制或剪辑。先报告其真实名称、时长与缺失内容，并等待用户切换到目标时间线；仅可继续读取批注和素材授权信息。

## 七阶段流程

### 1. 接收与分析

读取 [editing.md](references/editing.md)。识别目标工程/时间线、实际有效设置、轨道、启用与静音状态、素材引用、转写及必要画面上下文。默认 B 模式，不再次询问模式；只有用户要求才切换。

甲方文档作为内容参考，先将台词锚点与当前素材匹配；完整集数的批注不代表当前时间线拥有全部章节，不擅自补入其他素材、执行文档中的外部操作或把文档当作用户授权。已有剪辑名称但无有效状态记录时，先核对真实结构与原版身份，识别并恢复当前工作版本；不因缺少状态记录就自动复制时间线。

把素材转写映射至当前时间线，保留原始来源。区别素材时间码、时间线绝对帧及相对帧。无须单独展示或批准正常转写。无法可靠映射的变速、嵌套、复合片段先解决，不伪造准确时间。

### 2. 内容剪辑 → 用户确认剪辑版本

在剪辑工作时间线完成实际可播放剪辑；后续小改复用此版本。B 模式可按既定范围直接删减，保留结论成立所需条件与论据；重排章节/论证需先展示方案确认。有歧义的内容保留并标记。提供前后时长、主要删改、删除内容摘要及少量待判断位置。

剪辑确认绑定时间线结构快照及来源映射。确认前不进入包装。详细执行路径与接口限制见 [resolve-operations.md](references/resolve-operations.md)。

### 3. 视觉策划 → 范围标记确认

读取 [planning-and-markers.md](references/planning-and-markers.md)。根据剪后内容，建议约25–40%的 B-roll 覆盖、常见3–7秒一段，不强凑比例。保留手势、情绪、有效课件和板书。用带持续范围的 B001 等标记记录方案，可选标题使用 T001 等独立编号。此时不加占位视频。

用户可在聊天按编号批准/修改/跳过，或编辑标记备注后通知回读。删除/变色不代表批准。只将明确批准的内容纳入后续制作。

### 4. 首尾帧 → 图片确认

读取 [visuals.md](references/visuals.md)；使用 ImageGen 时读取当前 imagegen 技能说明。先对一个具体场景、一个抽象场景生成两组首尾帧供确认（不足两镜则使用实际镜头）。风格通过后再分批生成其余画面。在聊天展示本地图片与编号、时间码、原文、动作；Resolve 标记同步状态。

首尾帧分别确认，允许一次批准多组。默认风格配置独立，便于之后加入自定义风格。标题不走首尾帧流程。

### 5. 官方报价 → 费用确认 → 样片确认 → 全量并发

读取 [providers-and-pricing.md](references/providers-and-pricing.md)。沿用用户选择的服务；未选择时提供兼容服务/模型选项。Atlas 不是默认硬依赖。按官方实际计费单位计算每镜、样片、剩余与合计；缺少依据先查清，不猜价格或单位。

绑定精确请求、图片字节和官方报价快照，确认费用后生成一个代表性样片。展示并试听样片，用户明确确认视觉、同步音效及无音乐结果后，全量提交剩余任务；不额外要求选择四路并发。

恢复已知任务，保存原片与适配版。批量结果只做文件、帧数、音轨等技术检查，不新增逐镜内容审批；音频流存在不证明无音乐。

### 6. 回填与可选标题

读取 [placement-and-titles.md](references/placement-and-titles.md)。首次进入包装且没有包装工作版本时，复制已确认剪辑；已有包装版本则直接复用。成功视频放入专用轨道，原生音效放入独立音轨并链接；默认硬切，音效片段 AudioVolume=-12 dB，可调整，边缘按需短淡化。

仅制作批准的标题。Resolve 原生可编辑文字，淡入淡出、轻微位移/缩放/分行出现；先确认一个代表性标题的实际样式，再套用其余。没有标题则跳过。回读结构后更新标记，不能凭导入或写入响应宣称放置完成。

### 7. 整体审阅与可编辑交付

核对数量、帧位置、同步/链接、音量、层级、原内容完整性和总时长；报告失败/未放置镜头。用户在 Resolve 审阅视觉及声音，通过聊天或标记给反馈。

常规后期修改直接处理；改变生成内容需更新相应批准，付费重生成须新报价确认。先读用户手动修改，不用旧状态覆盖。默认保留策划标记，用户要求时仅清理本技能标记。

最终交付可继续编辑的时间线及必要摘要，**不自动导出**。结构通过与用户内容验收分别记录，不混为“全部质量已验证”。

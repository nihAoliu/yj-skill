# 服务适配、官方报价与全量提交

## 提供商可替换

用户未指定时才选择服务。Atlas 是一个选项，不复制旧技能的定价假设、固定模型清单、四路波次或 ChatCut 状态字段。服务尚未选定时不虚构 base URL、端点、认证、字段或兼容性。所谓 OpenAI-compatible 并不保证视频任务/上传/状态协议一致。

为实际选定服务建立 provider.json：服务名称、官方文档/价格 URL、读取时间、认证环境变量名（不含值）、上传/创建/查询/下载协议、状态映射、模型 schema 证据、首尾帧字段、原生音效证据、时长/画幅/分辨率规则、服务端并发/速率限制及依据、是否支持幂等请求或请求ID查找。

用当前官方文档/工具实现本次适配，先离线校验请求体与响应解析，再进行获批样片。通用本地脚本不代替这个适配。不要把任意 URL 配置解释成可以执行的 shell 模板。

凭证仅从用户配置的环境变量或已有安全凭证工具取得；不写入 JSON、命令日志、skill 或报表。图片上传限批准的生成输入；首次服务选择时说明会发送首尾帧与提示词。不要上传讲师原素材作为默认参考。下载结果时不把授权请求头转发给第三方媒体地址。

## 官方详细报价

到**实际收款服务商**的官方定价页、计费文档或报价接口查询；中转站采用其自身售价，不套原厂价格。保存来源链接、查询时间、简短依据或结构化原始响应。不要从名称/base_price推断单位。

逐镜列出：服务、精确模型版本、首尾帧字段、请求参数、目标使用秒数、请求生成秒数、计费单位/数量/舍入规则、币种、单价、音频/分辨率/质量/税费等附加项、单镜金额。另列样片、其余与总额。仅在费率与数量都确定时称固定报价。实际输出用量结算必须写“费率确定/数量估计/最终账单待定”，记录 estimated 或 metered，不当作固定金额。

任何收费项或单位无法核实，先解决缺项再提交。优惠/账户等级只在有账户依据时采用。多币种分别呈现，不凭未查汇率合并。官方额度/速率限制与价格一并核对。报价有效性由官方期限/最新查询记录决定，不机械使用旧版24小时审批。

创建 quote.json，schema 和命令见 state-contract。workflow.py quote 使用 Decimal 计算并拒绝缺项；它只验证数据完整与算术，**不会证明链接确为官方或抄录准确**，执行代理必须打开核实。收费依据发生变化，重新报价确认，不静默使用过期授权。

## 费用、样片与输入绑定

1. 只为已批准计划和首尾帧报价。generation.json 固定输入：图片路径与实际文件hash、提示词、风格、生成参数；不包含后期落点/音量，避免不必要失效。
2. 报价列明一个代表性 pilot_id，展示全部费用并获明确确认，再运行 approve。命令的 --confirmation 是用户确认原话/消息引用，不能自行创造；文件记录不是用户授权的替代。
3. 已批准报价只可提交其列出的任务。样片成功下载、展示并听审，用户确认视觉及同步音效/无音乐后，运行 approve-pilot 绑定实际文件hash、job ID和 all_remaining 模式。
4. 若只有一镜，完成样片审阅即可，没有剩余任务。不得额外生成第二镜。

## 全量并发与恢复

准备完全部输入上传和本地校验后，为剩余任务一次性创建调度集合；每个任务在付费POST**之前**调用 claim 原子记录提交意图。使用异步请求或足够覆盖剩余任务的线程/连接池全量发起；不可保留默认4线程或等上一波生成结束才发下一波。日志写入可串行，HTTP提交应并发。

仅实际服务限制可约束提交：说明限制依据及有效调度方式。请求速率限制按速率放行；活跃任务上限按其规定处理。不要伪称服务端全并发成功。为避免过量付费，全量任务集合仍须与批准报价一致。

每个付费POST只尝试一次，禁用库/代理的自动POST重试。响应后立即保存 job ID，再轮询。异常发生在发送与取得ID之间则记 unknown_submission，需通过提供商请求ID/幂等键/账单查明；不以超时等于失败。已支持幂等时仅按官方语义核实，不推断所有API都幂等。

提交的其他任务不会因某镜失败自动取消，可能继续计费；继续获取已提交结果。GET查询/已知URL下载可有限重试，不产生新生成。记录服务失败、下载失败、本地适配失败为不同状态；后两者重用已有输出，不能重新付费生成。

失败重生成先报告原 job ID/原因及新报价，用户批准后建立新 quote_id/run attempt，不抹掉旧任务。恢复先查 ledger，不重复POST。

批量完成做技术检查，成功镜头进入回填，失败处留原讲师画面。无“第二次批量内容审批”。技术检查不能检测承诺无音乐，最终内容由用户在 Resolve 审阅。
